# TaskManager

Aplicação de gerenciamento de tarefas composta por uma API REST desenvolvida com Java e Spring Boot e uma interface web para consumo da API.

## Estrutura do projeto

O projeto está dividido em duas partes:

### taskmanager-api

API REST responsável pelo gerenciamento das tarefas.

Tecnologias:

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

### taskmanager-web

Interface web simples para interação com a API.

Tecnologia:

- React

# Funcionalidades 

- Criar tarefas
- Listar tarefas
- Buscar tarefa por ID
- Atualizar tarefas
- Remover tarefas
